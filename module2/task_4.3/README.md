# Задание 4.3: Бинарное дерево с балансировкой (АВЛ-дерево)

Программа реализует базу данных контактов на основе самобалансирующегося АВЛ-дерева. АВЛ-дерево автоматически выполняет повороты при вставке или удалении элементов. Это гарантирует, что высота левого и правого поддеревьев любого узла отличается не более чем на 1,  поиск, вставка и удаление работают за логарифмическое время O(log N).

## Сборка и запуск
```bash
make          # Собрать программу
./app         # Запустить
make run_test # Запустить тесты
```

## Алгоритмы работы
Узел дерева (AVLNode)

Каждый контакт хранится в узле, который содержит:

Contact data - данные контакта (Фамилия и Имя).

int height - высота текущего узла, нужна для расчета баланса.

struct AVLNode *left - указатель на левого ребенка.

struct AVLNode *right - указатель на правого ребенка.

1. Сравнение контактов (compare_contacts)

Функция сравнения сначала сравнивает фамилии через strcmp. Если фамилии одинаковые, сравниваются имена.

2. Вставка с балансировкой (insert_node)

Сначала элемент вставляется как в обычное бинарное дерево поиска.

На обратном пути программа пересчитывает высоту узла и вычисляет баланс.

Если баланс выходит за пределы [-1, 1], выполняются повороты. В коде реализованы все 4 случая:

    Left-Left (LL): одинарный правый поворот.

    Right-Right (RR): одинарный левый поворот.

    Left-Right (LR): двойной поворот (левый для ребенка, затем правый для узла).

    Right-Left (RL): двойной поворот (правый для ребенка, затем левый для узла).

3. Удаление (delete_node)

Удаление листа - узел просто удаляется.

Удаление узла с одним ребенком - ребенок встает на место удаленного узла.

Удаление узла с двумя детьми - программа находит самый правый узел в левом поддереве, копирует его данные в текущий узел, а затем рекурсивно удаляет этот самый правый узел.
После удаления программа обязательно пересчитывает высоту и выполняет балансировку, чтобы дерево не развалилось.

4. Поиск (find_node_debug)

Поиск работает как в обычном BST, если искомое меньше, идем влево, больше - вправо.
В программе реализована отладочная версия поиска, которая выводит на экран путь по шагам с указанием, в какую сторону идем и считает количество сравнений.
