# Задание 6.2: Динамическая библиотека списка контактов

## Описание проекта
Логика работы со списком вынесена в отдельную динамическую библиотеку. В отличие от статической библиотеки, код библиотеки не вшивается в исполняемый файл программы, а загружается в оперативную память операционной системой во время запуска.

## Структура проекта
- `contacts.h` / `contacts.c` — модуль логики списка.
- `main.c` — консольный интерфейс.
- `Makefile` — сценарий сборки.
- `libcontacts.so` — динамическая библиотека.

## Как запустить
```bash
make                             # Собрать библиотеку и программу
LD_LIBRARY_PATH=. ./app          # Запустить
```

##Как работает
1. Компиляция логики с флагом -fPIC

отличие от статической сборки - это флаг -fPIC:

```make
CFLAGS = -Wall -Wextra -std=c99 -fPIC
```

Этот флаг говорит компилятору, что код может быть загружен в любое место оперативной памяти. Без этого флага динамическая библиотека не сможет работать, так как ОС загружает .so файл по случайному адресу.

2. Создание .so файла

Вместо утилиты ar мы используем флаг -shared линковщика:
```make

libcontacts.so: contacts.o
	$(CC) -shared -o libcontacts.so contacts.o
```

 -shared - создает разделяемую библиотеку, а не исполняемый файл.

3. Сборка программы

При сборке программы мы линкуем её с библиотекой:
```make

app: main.o libcontacts.so
	$(CC) $(CFLAGS) -o app main.o -L. -lcontacts
```

-L. - искать в текущей папке.

-lcontacts - подключить библиотеку libcontacts.so.
