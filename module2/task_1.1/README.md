Программа реализует книгу контактов на статическом массиве с возможностью добавления, редактирования и удаления записей. Реализована защита от ввода пустых имен и переполнения массива.

## Сборка и запуск
```bash
make          # Собрать программу
./phonebook   # Запустить
make run_test # Запустить тест
