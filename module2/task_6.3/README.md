# Задание 6.3: Калькулятор с динамической загрузкой плагинов

Программа реализует калькулятор, ядро которого ничего не знает о математических операциях. При запуске программа сканирует папку `plugins`, находит там динамические библиотеки, загружает их через `dlopen` и регистрирует найденные функции через `dlsym`. Чтобы добавить новую операцию, нужно просто скомпилировать новый плагин и положить его в папку.

## Структура проекта
- `calc.h` / `calc.c` - ядро (таблица команд + загрузка плагинов через dlopen).
- `main.c` - консольный интерфейс.
- `plugins/` - папка с исходниками и скомпилированными библиотеками.
- `Makefile` - сборка ядра и всех плагинов.

## Сборка и запуск
```bash
make          # Собрать ядро и все плагины
./app         # Запустить
```

## Библиотеки и как они используются
1. <dlfcn.h> - работа с динамическими библиотеками

Содержит 4 функции, которые мы используем:

    dlopen(path, RTLD_LAZY) - загружает .so файл в память. Возвращает ескриптор. Флаг RTLD_LAZY означает "разрешай символы по мере необходимости".

    dlsym(handle, "имя_функции") - ищет функцию по имени внутри загруженной библиотеки. Возвращает указатель на функцию.

    dlclose(handle) - выгружает библиотеку из памяти, когда она больше не нужна.

    dlerror() - возвращает текст последней ошибки.

2. <dirent.h> - чтение содержимого папки

    opendir(path) - открывает папку plugins.

    readdir(dir) - возвращает следующую запись в директории.

    closedir(dir) - закрывает папку.

## Описание каждой библиотеки

Все плагины лежат в папке plugins/. Каждый .c файл компилируется в .so. В каждом плагине обязательно есть 4 функции:

    get_op_name() - возвращает имя команды.

    get_op_descr() - возвращает описание команды.

    get_op_argc() - возвращает количество аргументов.

    op_execute(a, b, r) - сама математическая функция. Записывает результат в *r и возвращает код ошибки.

add.so (сложение)

    Аргументы: 2

    Функция: op_execute возвращает a + b.

    Ошибки: переполнение (inf/nan).

sub.so (вычитание)

    Аргументы: 2

    Функция: op_execute возвращает a - b.

    Ошибки: переполнение.

mul.so (умножение)

    Аргументы: 2

    Функция: op_execute возвращает a * b.

    Ошибки: переполнение.

div.so (деление)

    Аргументы: 2

    Функция: op_execute возвращает a / b.

    Ошибки: деление на ноль (b == 0), переполнение.

pow.so (степень)

    Аргументы: 2

    Функция: op_execute возвращает pow(a, b).

    Ошибки: 0^0 (область определения), 0^-1 (деление на ноль), nan (область определения), inf (переполнение).

mod.so (остаток)

    Аргументы: 2

    Функция: op_execute возвращает fmod(a, b).

    Ошибки: деление на ноль.

sqrt.so (корень)

    Аргументы: 1

    Функция: op_execute возвращает sqrt(a). Второй аргумент b игнорируется ((void)b;).

    Ошибки: корень из отрицательного числа.
