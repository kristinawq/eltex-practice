# Задание 3.2

## Описание
Программа имитирует обработку сетевых пакетов. Пользователь вводит IP-адрес шлюза, маску подсети и количество пакетов (N). Программа генерирует N случайных IP-адресов и считает статистику: сколько из них принадлежат своей подсети, а сколько чужим.

## Сборка и запуск
```bash
make          # Собрать программу
./app         # Запустить
make run_test # Запустить тесты
