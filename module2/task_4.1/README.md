# Задание 4.1: Двусвязный упорядоченный список контактов

## Описание
Программа реализует книгу контактов на основе двусвязного списка, упорядоченного по алфавиту. В отличие от статического массива, где элементы лежат в памяти подряд, здесь каждый контакт упакован в отдельный узел, связанный с соседями. Это позволяет эффективно вставлять и удалять элементы, не сдвигая весь массив.

## Алгоритмы работы
1. Упорядоченная вставка (add_contact)
При добавлении нового контакта программа не кладет его в конец. Она ищет место, чтобы список всегда оставался отсортированным по алфавиту (сначала по фамилии, затем по имени).
Создается новый узел через malloc
Проверяется, не должен ли новый узел встать в самое начало (если фамилия меньше, чем у head)
Если нет, запускается цикл поиска места. Мы идем по списку и сравниваем фамилии через strcmp. Как только находим элемент, который по алфавиту больше нового, мы останавливаемся и вставляем новый узел перед ним.
При вставке в середину переставляются 4 указателя: новый узел ссылается вперед на следующего, следующий ссылается назад на новый узел, предыдущий ссылается вперед на новый узел, новый узел ссылается назад на предыдущего
Счетчик count увеличивается

2. Удаление контакта (delete_contact)
Сначала мы находим узел, который нужно удалить, пробегая по списку до индекса index
Затем «вырезаем» его из цепочки: если у него есть предыдущий (current->prev), то его next перекидывается через удаляемый узел на следующий,если у него есть следующий (current->next), то его prev перекидывается на предыдущего,если удаляется самый первый элемент, то указатель head сдвигается на второй элемент
Память, выделенная под узел, освобождается через free()
Счетчик count уменьшается

3. Изменение контакта (edit_contact)
Если просто изменить данные внутри узла, то список потеряет свою сортировку. Поэтому изменение реализовано через композицию:
программа находит старый узел по индексу и удаляет его, затем вызывает add_contact, который вставляет обновленный контакт на правильное место по алфавиту.
