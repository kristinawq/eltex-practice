# Задание 6.1: Статическая библиотека списка контактов

Вся логика работы со списком  вынесена в отдельную статическую библиотеку. Главный файл программы только вызывает функции из этой библиотеки.

## Структура проекта
- `contacts.h` / `contacts.c` — модуль логики списка.
- `main.c` — консольный интерфейс.
- `Makefile` — сценарий сборки.
- `libcontacts.a` — статическая библиотека (создается при сборке).

## Как запустить
```bash
make      # Собрать библиотеку и программу
./app     # Запустить калькулятор
```

## Как работает
1. Компиляция логики

Сначала мы компилируем contacts.c в объектный файл contacts.o:
```make

contacts.o: contacts.c contacts.h
	$(CC) $(CFLAGS) -c contacts.c
```
Флаг -c означает только скомпилировать, не линковать.

2. Создание архива

Затем мы берем утилиту ar (archiver) и упаковываем contacts.o в файл libcontacts.a:
```make

libcontacts.a: contacts.o
	ar rcs libcontacts.a contacts.o
```

ar - утилита для создания архивов объектных файлов.

rcs - флаги: r (replace — заменить), c (create — создать), s (index — создать индекс для быстрого поиска функций).

Результат: файл libcontacts.a - статическая библиотека.

3. Сборка программы

Теперь мы компилируем main.c в main.o и линкуем его с нашей библиотекой:
```make

app: main.o libcontacts.a
	$(CC) $(CFLAGS) -o app main.o -L. -lcontacts
```
-L. - указывает линковщику искать библиотеки в текущей папке (.).

-lcontacts - указывает, какую библиотеку подключить. Линковщик сам ищет файл с именем libcontacts.a.
