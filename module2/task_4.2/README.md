# Задание 4.2: Очередь с приоритетом

## Описание проекта
Программа реализует очередь с приоритетом на основе односвязного списка. В отличие от обычной очереди, где элементы извлекаются по порядку поступления, здесь первыми извлекаются сообщения с наивысшим приоритетом. Приоритет задается целым числом от 0 до 255, где 0 - самый высокий приоритет

## Алгоритмы работы
1. Добавление с сортировкой (push)
Главная особенность функции push в том, что она не добавляет элемент в конец списка, а вставляет его в правильное место, чтобы список всегда оставался отсортированным по возрастанию приоритет.
1. Создается новый узел через malloc и заполняется данными.
2. Проверяется, не должен ли новый элемент встать в самое начало (если его приоритет меньше, чем у head).
3. Если нет, мы идем по списку, пока не найдем элемент, приоритет которого больше нашего. Вставляем новый узел перед ним.
4. Вставка в середину перестраивает ссылки next (связывает нового узла с «следующим»).
5. Счетчик count увеличивается.

2. Извлечение первого (pop_first)
Так как список всегда отсортирован по возрастанию, самый первый элемент всегда имеет самый высокий приоритет.
1. Запоминаем указатель на текущий head
2. Сдвигаем head на следующий элемент
3. Уменьшаем счетчик
4. Возвращаем указатель на извлеченный узел, чтобы main.c мог прочитать данные и освободить память через free()

3. Извлечение с конкретным приоритетом (pop_by_priority)
1.Мы идем по списку с двумя указателями: current  и prev.
2. Как только находим узел с нужным приоритетом, мы «вырезаем» его из списка:
  Если это head, то сдвигаем head на следующий.
  Если это середина, то prev->next перекидывается через найденный узел на следующий.
3. Возвращаем найденный узел. Если не нашли — возвращаем NULL.

4. Извлечение с приоритетом не ниже заданного (pop_at_least)
Функция ищет не точное совпадение, а элемент, приоритет которого не превышает порог (то есть более важный или равный по важности).
Особенность алгоритма: если в очереди есть несколько подходящих сообщений, функция извлекает наиболее близкий к порогу
1. Запускается цикл поиска по всему списку или до момента, пока приоритет не превысит порог
2. Среди всех элементов, которые прошли фильтр (priority <= threshold), запоминается тот, у которого приоритет максимальный
3. После завершения поиска найденный узел вырезается из списка, память возвращается в main.c
