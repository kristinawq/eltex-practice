# Задание 1: Копирование файлов через каналы pipe и fork

## Описание задачи
Программа копирует файлы, имена которых передаются в аргументах командной строки. Для каждого файла создается копия с расширением `.copy`. Процесс копирования разделен между двумя процессами: родителем и ребенком, которые общаются через каналы.

## Алгоритм работы программы

1. **Разбор аргументов**:
   - Программа проверяет наличие флага `-p`. Если он есть, следующим аргументом должно идти имя именованного канала (FIFO).
   - Все остальные аргументы - это список файлов для копирования.
   - Если файлы не переданы или допущена ошибка в аргументах, выводится справка.

2. **Создание каналов**:
   - Создается основной канал для передачи данных. Если был указан флаг `-p`, используется именованный канал (`mkfifo`), иначе  анонимный (`pipe`).
   - Создается второй канал `ready_fds` для синхронизации, чтобы ребенок мог сказать «Я готов».

3. **Разделение процессов**:
   - Программа создает дочерний процесс. С этого момента родитель и ребенок работают параллельно.

4. **Взаимодействие**:
   - **Ребенок:** 
     1. Отправляет в служебный канал сообщение `"READY"`.
     2. Ждет от родителя структуру с именем файла и его размером.
     3. Создает файл `*.copy` и читает данные из основного канала, записывая их в файл.
   - **Родитель:**
     1. Ждет сообщение `"READY"` от ребенка.
     2. Узнает размер файла. Если файла нет, выводит ошибку в `stderr` и переходит к следующему.
     3. Отправляет ребенку имя и размер, а затем читает файл блоками по 4 КБ и отправляет их в канал.

5. **Завершение**:
   - После передачи всех файлов родитель закрывает каналы, ждет завершения ребенка `waitpid` и удаляет именованный канал `unlink`.

## Сборка и запуск
```bash
make           # Сборка
make run_test  # Запуск тестов Unity
./copy_files -p pipe_name file1.txt file2.txt  # Запуск с именованным каналом
./copy_files file1.txt                         # Запуск с анонимным каналом
